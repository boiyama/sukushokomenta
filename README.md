# sukushokomenta

Web ページに埋め込む「スクショコメンター」です。画面をなぞって囲み、コメントを付けて、コメント入りの画像と GitHub の issue の下書きを作ります。開発・ステージング環境の画面の上で、デザインや文言のレビューをそのまま行うための道具です。

## 導入

1. `package.json` に追加します。

```json
"@boiyama/sukushokomenta": "git+https://github.com/boiyama/sukushokomenta.git#v0.1.1"
```

2. アプリのエントリで `init()` を呼びます。

```ts
import { init } from "@boiyama/sukushokomenta";

init({ repo: "owner/repo" });
```

### オプション

| 名前 | 説明 |
|---|---|
| `repo` | `owner/repo`(必須)。issue を立てるリポジトリ |
| `button` | `false` で起動ボタンを出さない(既定 `true`)。PC で Shift 2 回だけで起動したいとき用 |

`init()` の返り値の関数を呼ぶと、解除できます。

## 使い方

1. 画面の端の丸いボタン(PC では Shift を 2 回すばやく押す)で、コメントモードを開きます。そのとき見えている範囲が画像になります。
2. 気になるところを指でなぞって囲み、コメントを書きます。囲いをタップするとコメントを編集でき、番号の横の 🗑 で削除できます。
3. メニューの「送信待ち」で、撮ったスクショの一覧を開きます。スクショを開いてコメントを足したり、サムネイルの 🗑 でスクショごと、「すべて削除」でまとめて削除したりできます。
4. 「① 画像をコピー」を押してから「② issue を作成」を押し、開いた画面の本文の先頭に画像を貼り付けて、Submit します。

メニューの「モード解除」(PC では Esc でも)で、元の画面に戻ります。

送信待ちのコメントは、モード解除しても再読み込みしても消えず、ブラウザに残ります(最大 10 件)。別の画面に移ってコメントを足していけば、複数の画面へのコメントを 1 つの issue にまとめられます。送信したあとも自動では消えないので、不要になったら「すべて削除」で消してください。
